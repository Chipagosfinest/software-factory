# Imbue Sculptor

*Refreshed 2026-11-02*

## What they do

Sculptor is Imbue's interface for parallel coding agents. The product page says agents run in containers and that the UI is there to see and verify their changes, and to keep context between sessions.

## What they do well

The first-party claim is isolation plus a review surface, not a benchmark. A market survey describes Sculptor as wrapping Claude Code and Codex in Docker and labels it an experimental preview; that survey is not needed for the container and verification claims, which are on Imbue's page.

## Patterns shown

- [Background agents](../patterns/background-agents/README.md) — parallel agents in containers
- [Verification](../patterns/verification/README.md) — the UI is for checking what those agents changed
