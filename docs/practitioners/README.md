# Practitioners

Parent hub for teams and products that show the patterns in production or in a public system. Each profile uses the same template: what they do, what they do well (cited), patterns shown, key numbers, sources.

Pattern notes keep the mechanism. These profiles keep the team-specific record. The one-liners below are the short citations.

## Practitioners doing this well

- [Stripe Minions](./stripe-minions.md) — one-shot devboxes, about 1,300 merged pull requests a week ([Stripe](https://stripe.dev/blog/minions-stripes-one-shot-end-to-end-coding-agents)).
- [Spotify Honk](./spotify-honk.md) — fleet Kubernetes jobs and an LLM judge that vetoes about a quarter of diffs ([Honk, part 3](https://engineering.atspotify.com/2025/12/feedback-loops-background-coding-agents-part-3)).
- [Ramp Inspect](./ramp-inspect.md) — snapshot sandboxes; the Modal/Ramp writeups in this repo put Inspect near half of merged pull requests ([Modal](https://modal.com/blog/how-ramp-built-a-full-context-background-coding-agent-on-modal)).
- [Open-Inspect](./open-inspect.md) — open-source three-tier clone of that shape ([GitHub](https://github.com/ColeMurray/background-agents)).
- [OpenAI Codex](./openai-codex.md) — internal product of about 1M lines and no hand-written code ([harness engineering](https://openai.com/index/harness-engineering/)).
- [StrongDM Software Factory](./strongdm-software-factory.md) — specs and scenarios drive agents that write code and converge without human writing or review; guideline about $1,000 of tokens per engineer per day ([factory.strongdm.ai](https://factory.strongdm.ai/)).
- [Cognition Devin](./cognition-devin.md) — cloud sandboxes; Nubank's 12x claim is vendor-reported ([Devin](https://devin.ai)).
- [LangChain Deep Agents](./langchain-deep-agents.md) — +13.7 percentage points on Terminal Bench 2.0 with the model held fixed ([LangChain](https://blog.langchain.com/improving-deep-agents-with-harness-engineering/)).
- [Anthropic Claude Code](./anthropic-claude-code.md) — terminal agent; historical 80.9% SWE-bench Verified, later flagged as a weak benchmark ([landscape](../landscape/README.md)).
- [Amp](./amp.md) — waits for a fix to roll out, then emails the reporter and everyone else who hit the bug ([post](https://x.com/AmpCode/status/2115912054964179204)).
- [Vercel](./vercel.md) — agentic CI: inspect, abort, trigger, and replay runs; 20 clusters ([post](https://x.com/rauchg/status/2115539426684408300)).
- [Replit Agent Habitat](./replit-agent-habitat.md) — a contained space whose boundary limits what an unpredictable agent can do ([post](https://x.com/amasad/status/2115485095251308740)).
- [OpenHands](./openhands.md) — open-source Docker sandboxes; 77.6% SWE-bench Verified in the landscape pass ([OpenHands](https://openhands.dev/)).
- [Goose](./goose.md) — Block's open-source agent; Stripe's Minions are a fork ([GitHub](https://github.com/block/goose)).
- [Cline](./cline.md) — VS Code agent that asks before it acts; 5M+ installs in the landscape pass ([Cline](https://cline.bot/)).
- [Paperclip](./paperclip.md) — org chart and per-agent budgets; 57.4K stars as of April 2026 ([GitHub](https://github.com/paperclipai/paperclip)).
- [Composio Agent Orchestrator](./composio-agent-orchestrator.md) — one worktree per agent, eight plugin slots ([GitHub](https://github.com/ComposioHQ/agent-orchestrator)).
