# JetBrains Junie

*Refreshed 2026-11-02*

## What they do

Junie is JetBrains' coding agent, with a local product, a CLI, and a web app mentioned on the product page. The page lists tasks such as Spring Boot upgrades and adding test coverage, and it says guidelines and skills teach Junie a team's conventions.

## What they do well

The verifiable claim from this page is that Junie is positioned to change code and to add tests under team guidelines. The page does not describe running the IDE's inspection engine as a gate, so this profile does not claim that.
