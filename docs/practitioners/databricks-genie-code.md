# Databricks Genie Code

*Refreshed 2026-11-02*

## What they do

Genie Code is Databricks' coding agent for data work, introduced on the Databricks blog. The post's example objective is to identify flight-delay risks and build a monitoring dashboard. The agent plans and executes across data tools.

## What they do well

Databricks says that on an internal benchmark of real-world data science tasks, Genie Code more than doubles the success rate of a leading coding agent. The comparison set and the denominator are internal. No public task list is in the post.
