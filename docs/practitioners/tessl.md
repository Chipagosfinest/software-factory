# Tessl

*Refreshed 2026-11-02*

## What they do

Tessl's site calls itself a software factory built from skills: "from skills to loops to factory." The Tessl Registry is a searchable index of skills across an organization and a private workspace. The homepage's "executable specs" line is a talk title, not the product description used here.

On November 2, 2026, Tessl said it had repositioned from context for coding agents to a platform for building software factories, with ready-made loops for Ticket to PR and Code Review, or custom loops.

## What they do well

The registry is aimed at skill sprawl: find an existing skill before writing a duplicate. Tessl also says you can see whether skills are actually activated and run before-and-after evals on each change. Skills in the registry are scanned and scored before install. The page offers a free start of 1,000 credits a month. It does not describe a spec registry as the artifact.
