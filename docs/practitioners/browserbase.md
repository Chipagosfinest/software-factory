## What they do

Browserbase's docs describe a browser API: create, control, and observe browser sessions, plus an agents API for structured extraction. The introduction page used here does not say "headless," so that word is not the claim.

## What they do well

The session is the verification surface for UI work. No concurrency number is taken from this page.
