# Factory.ai

*Refreshed 2026-11-02*

## What they do

Factory's docs index describes a product surface for coding agents: Missions, Droids, computers and environments, and remote control, plus harness customization and model independence. This profile does not repeat leaderboard ranks from other notes in this repo.

On October 30, 2026, Factory said it acquired Typedef, a context layer that helps agents understand enterprise data, so Droids have clearer lineage and evidence for migrations, pipeline debugging, and model refactors. The same day, @matanSF wrote: "People often over-index on the code generation step. Enterprise agents live or die by the data."

## What they do well

The docs present Missions and Droids as the way work is packaged, with environments the agent runs in and a remote-control path. Autonomy and safety are a documented section, which is the harness boundary rather than a measured outcome.
