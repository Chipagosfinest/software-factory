# Kilo Code

*Refreshed 2026-11-02*

## What they do

Kilo's README describes an open-source coding agent for VS Code, JetBrains, or the CLI. It says you can pick from 500+ models, switch mid-task, and pay the provider's rate with no markup.

## What they do well

The README does not describe an orchestrator mode or call the project a superset of Cline or Roo. Those claims are not used. What it does support is a multi-client agent with an explicit model choice.

## Patterns shown

- [Harness engineering](../patterns/harness-engineering/README.md) — one open-source agent across editor and CLI, model chosen per task
