## What they do

Runloop's docs describe devboxes: a lifecycle, command execution, files, and blueprints that define the box. Remote agents are a documented section. A public benchmark suite is not what the introduction page describes, so this profile does not claim one.

## What they do well

The blueprint is the reusable environment definition. The devbox is the machine the agent runs on.
