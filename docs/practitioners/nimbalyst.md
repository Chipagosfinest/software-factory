# Nimbalyst

*Refreshed 2026-11-02*

## What they do

Nimbalyst's site title is an agent wiki and workspace for Claude Code and Codex. The GitHub repository describes a MIT-licensed desktop app for Claude Code, Codex, and OpenCode that runs multiple coding agents in parallel and tracks tasks. Repository topics include a worktree manager.

## What they do well

The first-party detail is the parallel workspace, not a measured merge rate. A market survey adds an iOS companion and Aider support; those are not on the site title or the GitHub description used here, so they are left out. There is enough first-party description to keep the profile.

## Patterns shown

- [Orchestration](../patterns/orchestration/README.md) — a desktop workspace for several coding agents at once
- [Background agents](../patterns/background-agents/README.md) — parallel sessions, with worktrees as a repository topic
