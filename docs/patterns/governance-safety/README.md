# Governance and Safety

*Refreshed 2026-11-01*

Parent hub for keeping agent throughput inside limits: budgets, kill switches, approval gates, blast radius, and the review tools that sit on the pull request.

Speed without a cap shows up as spend, as review debt, or as a change the tests did not describe. Governance here is mechanical: a budget the run cannot exceed, a timeout, a tool allowlist, and a human gate where the risk tier requires one.
