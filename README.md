# Software Factory

A research corpus on agent-native software delivery: how teams wire coding agents, what they verify before merge, and which topologies show up in production.

For humans evaluating agentic software development, and for agents navigating the corpus. Humans start at the decision map, then one hub. Agents parse the index and open only the nodes they need. Practitioner profiles hold the cited team one-liners. Pattern hubs hold the mechanisms. Dated surveys are archived snapshots; the landscape map is the current state of play.
